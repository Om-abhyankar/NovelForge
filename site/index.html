What it actually does

Most novelists piece this together from five different apps. NovelForge bundles it into one that opens in about a second.

✍️

While you write

  • Real .docx files, one per scene — edit in Word or in-app, always in sync
  • Focus mode, distraction-free mode, ghost mode, typewriter scrolling
  • Live spelling/grammar tuned to your manuscript's own names and invented words
🗺️

Planning & structure

  • Nine outline frameworks — Three-Act, Save the Cat, Snowflake, Seven-Point, and more
  • Corkboard with drag-to-reorder index cards
  • Real Word reference sheets for characters, locations, items, factions, threads
🕸️

World & story intelligence

  • The story graph mines your prose for every character, place and object mention
  • A 15-point continuity checker — dates, deaths, dropped plot threads
  • One-click Story Bible generation, always current
🏰

Maps & worldbuilding

  • One-press procedurally generated fantasy worlds — coastlines, kingdoms, rivers, roads
  • Editable per-culture name generation
  • Hand-drawn tools: freehand coastlines, 20 pin types, 4 art styles
🛡️

Never losing your work

  • Atomic writes, per-document version history, verified zip backups
  • A crash-recovery journal that asks before it restores anything
  • Full undo/redo for structural edits — delete a chapter, get it back
🔍

Offline diagnostics

  • ~20 prose checks — adverbs, filter words, passive voice, pacing, word echoes
  • A five-type writer's-block diagnostic, ranked by actual prevalence
  • A pace/streak/deadline dashboard
Look inside

A tool built for exploring, not just typing

Map Maker — Gnashrok and Beyond
Maps

A whole fantasy world, one click

Press "Surprise Me" for a complete world — coastlines, kingdoms, rivers, roads, dozens of named settlements — built from the system's own randomness. Every world remembers its seed, so one you like can be regenerated exactly. Prefer to draw it yourself? Freehand coastlines, 13 terrain types and 20 pin types are there too.

Corkboard
Corkboard

See the shape of the whole book

Every scene as an index card, grouped by chapter, colour-coded by status. Drag a card onto another to reorder it, or onto a chapter heading to move it there. This is the fastest way to outline, because you can see everything at once.

Outline & Beats — Three-Act Structure
Planning

Nine frameworks, switch freely

Three-Act, Save the Cat, Snowflake, Seven-Point, Story Circle, Hero's Journey, Romancing the Beat, Mystery/Crime, Freytag. Each beat shows the word position it should land at, calculated from your own target length. Try one, switch to another — nothing is lost.

Getting started

Three steps, no technical background needed

1

Install Python

Free, from python.org — tick "Add python.exe to PATH" during setup. One-time, a couple of minutes.

2

Download NovelForge

Grab the latest release from GitHub and unzip it anywhere on your PC — your Desktop or Documents folder is fine.

3

Double-click Write.bat

That's it. It finds Python on its own and opens straight into the app. File → New Novel... to begin.

🪟 Windows 10 & 11
🍎 macOS — not yet
🐧 Linux — not yet

NovelForge's engine is plain Python, but its interface is built with Tkinter and has only ever been tested on Windows. macOS/Linux support is a real possibility, not a promise — open an issue if that's what would get you using it.
