# Code of Conduct

This is a small hobby project made by one person for other writers. The
standard is simple:

- Be respectful. Disagree with a decision or a piece of code without being
  unpleasant about the person who wrote it.
- No harassment, insults, or personal attacks, in issues, pull requests, or
  anywhere else connected to this project.
- Assume good faith. Most bugs are bugs, not malice, and most confusing
  decisions have a reason even if it isn't written down yet.

If someone is being a problem in this project's spaces, open an issue
tagging the maintainer, or contact them directly. Reports will be handled
privately, and anyone asked to stop a behaviour and doesn't will be blocked
from the project.

This is intentionally short because the project is small. If NovelForge
ever grows a real community, this file should grow with it — the
[Contributor Covenant](https://www.contributor-covenant.org/) is the
standard starting point for that.
